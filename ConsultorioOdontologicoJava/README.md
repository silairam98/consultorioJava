# Consultorio Odontológico en Java
Sistema de escritorio desarrollado en Java 21 con conexión a MySQL.

## Requisitos
- Java JDK 21
- MySQL Server / XAMPP

## Instalación de la Base de Datos
1. Abre tu gestor de MySQL.
2. Crea una base de datos llamada `consultorio_java`.
3. Importa el archivo `consultorio_java.sql` incluido en este proyecto.
